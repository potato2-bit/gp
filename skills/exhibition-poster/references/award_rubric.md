# Special Innovation Award — the judge's checklist

Source: `Downloads/Special Innovation Award Template.pdf` ("Final Bootcamp Output Template —
From Graduation Project to Real-World Impact"). The award is scored on nine questions plus a
final readiness checklist. Treat each as something a judge will look for. The poster answers
all nine silently; the deck answers them out loud, one per slide.

## The nine questions

1. **Project Information** — title, team, program/school, supervisor, project type (this one
   is "Hardware / device" + "Prototype / technical solution" + "Social / environmental impact
   solution"). Goes on the poster header and the deck title slide.

2. **The Problem** — *What real problem, for whom, when/where, why it matters, and what's wrong
   with current solutions?* Use the template's frame: "Our project addresses the problem of ___
   faced by ___ when ___ because ___. Current solutions are limited because ___."

3. **User / Customer** — *Who is it for? Be specific — never "everyone."* Separate the user who
   lives the problem, the decision-maker who says yes, and the payer who funds it.

4. **User Insight & Evidence** — *What evidence shows the problem is real?* Interviews,
   observations, field data, academic references, industry/market data, supervisor feedback,
   prototype tests. Judges reward evidence over assertion — show what you have and what you'll
   collect.

5. **The Solution** — *What is it, in language a non-specialist understands?* What it does, how
   it works at a simple level, what makes it different, and the current stage of development.

6. **Value Proposition** — fill the formula exactly: "For ___ who face ___, our solution
   provides ___ by ___, unlike current alternatives that ___."

7. **Impact Potential** — fill the formula: "If implemented, our project can help ___ achieve
   ___ by ___, leading to ___." Then attach numbers (water saved, energy recovered, cost cut,
   safety, users served).

8. **Demo / Prototype Readiness** — *What will you show at the exhibition?* What's demonstrated,
   which form (live demo, physical prototype, simulation, video, poster, model), what already
   works, the setup needed, and the **backup plan if the demo fails.** Judges notice teams who
   planned for failure.

9. **Business Model Canvas Snapshot** — customer segments, value proposition, channels, customer
   relationships, revenue/funding model, key resources, key activities, key partners, cost
   structure. A compact BMC table covers this.

## Final readiness checklist (the team must answer cleanly)

- What problem are we solving?
- Who needs or benefits from our solution?
- What evidence do we have?
- What value do we create?
- What impact could we generate?
- How will we demonstrate the project?
- How can it move beyond the exhibition?
- What assumptions still need validation?

## How the rubric maps to the deck (the 10 "innovation for impact" slides)

| Deck slide | Rubric section(s) it satisfies |
|---|---|
| 1. Title | Project Information + the one-line hook |
| 2. Project title & team | Project Information |
| 3. Main problem / industry gap | The Problem |
| 4. Target users / beneficiaries | User / Customer + User Insight & Evidence |
| 5. Proposed solution & prototype | The Solution + Demo / Prototype Readiness |
| 6. Value proposition | Value Proposition |
| 7. Market / sector research | User Insight & Evidence (industry/market data) |
| 8. Potential impact | Impact Potential |
| 9. Business model / adoption pathway | Business Model Canvas Snapshot |
| 10. Next validation steps | "What assumptions still need validation?" |

## How the rubric maps to the poster zones

Header → Project Information. Hook strip → the memorable one-liner. Problem card → §2. Users
card → §3–4. Solution + system diagram → §5. Big stat band → §7 impact, with §6 value. Three-
scale market block → §7 deck / market. Prototype status + next steps → §8 + assumptions. Footer
→ author, supervisor, course, contact, QR. A small BMC strip or "how it scales" line covers §9.
